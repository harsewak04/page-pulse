# 🚀 Page Pulse

Page Pulse is a Flask-based web application that analyzes a webpage and provides useful SEO and webpage insights.

## Features

- Analyze any valid webpage URL
- HTTP Status Code
- Response Time
- Page Title
- Meta Description
- H1 Tag Count
- Images Missing ALT Text
- Word Count
- User-Friendly Error Handling
- Non-HTML Content Detection

## Technologies Used

- Python
- Flask
- Requests
- BeautifulSoup4
- HTML
- CSS
- JavaScript

## Installation

1. Clone the repository

```bash
git clone <your-repository-url>
```

2. Install dependencies

```bash
pip install -r requirements.txt
```

3. Run the application

```bash
python app.py
```

4. Open your browser

```
http://127.0.0.1:5000
```
